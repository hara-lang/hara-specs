# Planning archive

This directory contains source material that predates the machine-readable HAL
meta-spec and language specification.

The files are grouped by domain to make their design history discoverable.
They are historical and non-normative: active specifications may cite them as
provenance, but cannot depend on them for current language requirements.

Current draft authority lives in:

- [`../../metaspec/draft/hal-metaspec.edn`](../../metaspec/draft/hal-metaspec.edn)
- [`../../language/draft/hal-langspec.edn`](../../language/draft/hal-langspec.edn)
